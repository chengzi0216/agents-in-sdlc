Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y una lista de tareas compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de cambios y gestionar el trabajo con agentes.

## Situación

Eres una nueva persona desarrolladora en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. La lista de tareas del equipo ya está registrada como incidencias de GitHub, listas para que elijas una. Incluye trabajo de funcionalidades, como filtros y paginación, además de mejoras de calidad, como accesibilidad y estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza la situación compartida de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente agéntico en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [GitHub Copilot app][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en canvas y gestiona incidencias y solicitudes de cambios de GitHub en la aplicación de escritorio.

### [GitHub Copilot cloud agent][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
